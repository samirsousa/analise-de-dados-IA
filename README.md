## 🎯 Objetivo do Repositório
Demonstrar competência técnica prática em toda a cadeia de valor de dados e inteligência artificial: desde a exploração automatizada e engenharia de features até a exposição de modelos via API e construção de interfaces interativas para usuários finais.

## 🏗️ Arquitetura & Padrões de Projeto
- **Isolamento Total:** Cada projeto está contido em sua própria pasta com dependências e dados simulados (mock data) independentes.
- **Zero Friction:** Projetos desenhados para rodar imediatamente sem necessidade de configurações complexas de infraestrutura ou chaves de API externas obrigatórias.
- **Modularidade:** Código fortemente tipado (Type Hints), limpo e documentado.
