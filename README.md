# 🚀 AI & Analytics Hub

Repositório dedicado a soluções de análise de dados, machine learning, automações analíticas e inteligência artificial aplicada. Este espaço complementa minha stack de engenharia, focando em inteligência de dados, modelagem preditiva e produtos de IA.

---

## 📌 Sumário de Módulos & Projetos

| # | Projeto | Descrição Principal | Tecnologias Chave |
|---|---|---|---|
| **01** | **[Smart EDA Agent](01_smart_eda_agent/)** | Automação de relatórios estatísticos e insights executivos em Markdown. | Python, Pandas, NumPy |
| **02** | **[Churn Predict Engine](02_churn_predict_engine/)** | Pipeline de Machine Learning para predição de evasão de clientes com API REST. | Python, Scikit-Learn, FastAPI, Pydantic |
| **03** | **[NLP Sentiment Pulse](03_nlp_sentiment_pulse/)** | Processamento de lotes e diagnóstico de ofensores/dores em feedbacks. | Python, NLP, Análise Léxica, Pandas |
| **04** | **[Smart SQL Copilot](04_smart_sql_copilot/)** | Interface conversacional interativa para tradução de linguagem natural em SQL. | Python, Streamlit, SQLite, Pandas |
| **05** | **[Football Scout Analytics](05_football_scout_analytics/)** | Cálculo de índices compostos de eficiência (Scout Score) e métricas de atletas. | Python, Pandas, NumPy |

| **07** | **[RAG Document Copilot](07_rag_document_copilot/)** | Assistente de Q&A com recuperação vetorial local (TF-IDF + Cosine) sobre contratos e manuais. | Python, Streamlit, Scikit-Learn, Pandas |

## 🛠️ Stack Tecnológica Geral
- **Linguagens:** Python 3.10+, SQL (ANSI / SQLite dialect)
- **Engenharia & Análise:** Pandas, NumPy, Scikit-Learn
- **Modelagem Preditiva & IA:** K-Means, Isolation Forest, Random Forest, TF-IDF Vector Retrieval (RAG)
- **Interfaces & APIs:** Streamlit, FastAPI, Uvicorn, Pydantic
- **Visualização & Relatórios:** Plotly (HTML interativo), Standard Markdown
