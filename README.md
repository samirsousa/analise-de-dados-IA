# 🚀 AI & Analytics Hub

Repositório dedicado a soluções de análise de dados, machine learning, automações analíticas e inteligência artificial aplicada. Este espaço complementa minha stack de engenharia, focando em inteligência de dados, modelagem preditiva e produtos de IA.

---

## 📌 Sumário de Módulos & Projetos

| # | Projeto | Descrição Principal | Tecnologias Chave |
|---|---|---|---|
| **01** | **Smart EDA Agent** | Automação de relatórios estatísticos e insights executivos em Markdown. | Python, Pandas, NumPy |
| **02** | **Churn Predict Engine** | Pipeline de Machine Learning para predição de evasão de clientes com API. | Python, Scikit-Learn, FastAPI |
| **03** | **NLP Sentiment Pulse** | Processamento de lotes e classificação de polaridade em feedbacks. | Python, NLP, Análise de Texto |
| **04** | **Smart SQL Copilot** | Interface conversacional interativa para tradução de linguagem natural em SQL. | Python, Streamlit, SQLite |
| **05** | **Football Scout Analytics** | Cálculo de índices compostos de eficiência e métricas de atletas. | Python, Pandas, NumPy |

## 🛠️ Stack Tecnológica Geral
- **Linguagens:** Python 3.10+, SQL (ANSI / SQLite dialect)
- **Engenharia & Análise:** Pandas, NumPy, Scikit-Learn, SQLAlchemy
- **Interfaces & APIs:** Streamlit, FastAPI, Uvicorn
- **Visualização:** Plotly, Matplotlib, Seaborn
